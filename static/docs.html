Technical Specification

SkyGuard Sentinel ADSB REST API

Real-time surveillance interface providing live global flight state vectors, military airframe identification, geospatial FIR Indonesia boundary verification, and transponder emergency evaluation.

Protocol HTTP/1.1 REST
Payload Format JSON (UTF-8)
Compression Gzip (Automatic)
Cross-Origin CORS Enabled (*)
State Cache TTL 15 Seconds
Database Index 494,976 Airframes

Network & Caching Policy

Technical constraints, CORS configuration, and payload compression

AspectSpecificationDetails
CORS Policy Access-Control-Allow-Origin: * Permits direct client-side fetch from single-page web applications and mobile clients.
Rate Control 15-second refresh cycle In-memory caching prevents redundant external upstream requests while serving local clients instantly.
Gzip Encoding Level 5 Gzip Compression Compresses 2.5 MB payloads down to ~250 KB when client sends Accept-Encoding: gzip.
Authentication None (Internal / LAN) Open local network access. Upstream token management with OpenSky OAuth2 is handled internally.
GET /api/all-flights
Global flight vectors (Commercial + Military)

Returns active airborne transponder state vectors worldwide. Each aircraft is enriched with verified registration, ICAO type code, airline/military operator, FIR Indonesia boundary flag, and anomaly detections.

Query Parameters
ParameterTypeDescription
mode OPTIONAL string Fleet sector filter.
Values: 'all' (default) | 'military' | 'commercial'
category OPTIONAL string Airframe subtype filter.
e.g. 'heavy', 'airline', 'cargo_commercial', 'fighter', 'turboprop', 'business_jet', 'helicopter'
in_fir OPTIONAL boolean When true or 1, filters for flights positioned inside Jakarta (WIIF) or Ujung Pandang (WAAF) FIR airspace.
emergency OPTIONAL boolean When true, returns only flights broadcasting squawk 7700/7600/7500 or kinematic flight anomalies.
country OPTIONAL string Filters by country of registration (e.g. Indonesia, United States).
q OPTIONAL string Substring search across callsign, ICAO hex, tail registration, or operator name.
limit OPTIONAL integer Limits the maximum count of returned flight records.
Status Codes
200 OK — Telemetry vector array 400 Bad Request — Invalid parameter syntax 
curl -s "http://localhost:8080/api/all-flights?in_fir=true&limit=5"
// Click "Execute" to inspect live response

GET /api/military-flights
Dedicated defense & tactical airframe feed

Delivers only verified military aircraft, air defense transports, aerial refuelers, combat jets, and reconnaissance platforms matched against military database hex ranges.

Parameters

Accepts identical query parameters as /api/all-flights (e.g. category, in_fir, emergency, limit).

Standard Flight Object Fields
KeyTypeDescription
icao24string6-character transponder hex identifier.
callsignstringOperational tactical callsign or registration.
type_codestringICAO airframe type code (e.g. C17, F16, B738).
descstringFull manufacturer and model description.
categorystringClassified silhouette category key.
operatorstringArmed force, squadron, or commercial operator.
in_fir_indonesiabooleanIndicates presence within Indonesian FIR boundary.

GET /api/track/{icao24}
Coordinate breadcrumb trail history

Retrieves coordinate history recorded for an individual transponder address over recent scan intervals. Used to render route tracks on radar canvases.

Path Parameter
ParameterTypeDescription
icao24 REQUIRED string (hex) 6-character ICAO24 transponder identifier (case-insensitive).
Array Structure

Each element in trail is a 4-item tuple: [latitude, longitude, altitude_ft, unix_timestamp]. 

curl -s "http://localhost:8080/api/track/7500DA"
// Click "Execute" to retrieve flight track

Emergency Squawks & Anomaly Codes

Transponder event codes generated by the flight anomaly surveillance engine

Detection CodeSeverityTrigger CriteriaICAO Operational Meaning
squawk_7700 CRITICAL Squawk == "7700" General in-flight emergency declared by flight crew.
squawk_7600 CRITICAL Squawk == "7600" Radio failure / Lost two-way air traffic communication.
squawk_7500 CRITICAL Squawk == "7500" Unlawful interference / Hijacking alert.
rapid_descent CRITICAL Vertical speed ≤ -3,500 fpm Emergency descent rate (e.g. depressurization or control event).
rapid_climb WARNING Vertical speed ≥ +3,800 fpm High climb rate / Scramble intercept ascent profile.
supersonic WARNING Ground speed ≥ 550 kts High-speed dash / Transonic or Supersonic flight regime.
fir_violation WARNING Foreign military in FIR Foreign military aircraft active within Jakarta or Ujung Pandang FIR.
spi_ident INFO SPI transponder flag == true Special Position Identification pulse requested by ATC radar controller.
